# Codex Caelestis: The Judicial Astrology Engine

Welcome to the documentation for **Codex Caelestis**, a state-of-the-art computational engine for forensic astrology. This platform restores the rigorous, logic-based methodologies of the classical tradition (Hellenistic, Medieval, Renaissance) using modern software architecture.

## Overview

The Codex Caelestis engine is designed to go beyond "sun sign" horoscopes. It implements complex, hierarchical decision trees used by master astrologers like Ptolemy, Valens, Bonatti, and Lilly, codified into a deterministic **Rule Ledger**.

### Key Features

*   **Forensic Accuracy**: Every judgment is traced back to a primary source citation.
*   **The Auditor**: A centralized decision engine that orchestrates dignity analysis, fate determination, and medical auditing.
*   **Rule Ledger**: A transparent, audit-trail output explaining *why* a specific judgment was made.
*   **B2B/Practitioner Focused**: API-first design for integration into professional dashboard tools.
