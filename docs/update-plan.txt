## Overview

### Target State

* **Architecture:** Modular FastAPI router structure (`src/api/v1/`) served by a main entry point.
* **Concurrency:** Non-blocking execution of the synchronous calculation engine using FastAPI's threadpool.
* **Database:** Optimized, normalized schema (dropping `User.subscription_tier` entirely in favor of `UserSubscription`).
* **Configuration:** Robust environment variable management using `pydantic-settings`.

## Phase 1: Database & Configuration

### Step 1: Secure Configuration Management

**Goal:** Replace the fragile `_load_dotenv` function in `src/api.py` with a robust configuration class.

1. **Create `src/core/config.py`:**
Use `pydantic-settings` to validate essential vars (`STRIPE_SECRET_KEY`, `JWT_SECRET`, `REDIS_URL`) on startup. Fail fast if missing.
```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    STRIPE_SECRET_KEY: str
    STRIPE_WEBHOOK_SECRET: str
    JWT_SECRET: str
    REDIS_URL: str = "redis://localhost:6379"

    class Config:
        env_file = ".env"

settings = Settings()

```



### Step 2: Database Schema (Clean Slate)

**Goal:** Implement a strictly normalized schema without legacy columns.

1. **Update `src/database/models.py`:**
* **Remove:** `User.subscription_tier`, `User.subscription_expires`.
* **Add:** `SubscriptionPlan`, `UserSubscription`, `UsageRecord`, `ApiKey`.
* **Refactor:** Ensure `User` model is clean and relies purely on the relationship to `UserSubscription`.


```python
from sqlalchemy import Column, String, DateTime, Integer, Boolean, ForeignKey, JSON, Numeric
from sqlalchemy.orm import relationship
from datetime import datetime
import uuid
from .core import Base

class User(Base):
    __tablename__ = "users"
    id = Column(String, primary_key=True, default=lambda: str(uuid.uuid4()))
    email = Column(String, unique=True, nullable=False)
    # ... other core user fields ...

    # Relationship only - no legacy columns
    subscription = relationship("UserSubscription", back_populates="user", uselist=False)
    api_keys = relationship("ApiKey", back_populates="user")

class SubscriptionPlan(Base):
    __tablename__ = "subscription_plans"
    id = Column(String, primary_key=True, default=lambda: str(uuid.uuid4()))
    tier = Column(String(20), unique=True, nullable=False) # e.g., 'practitioner'
    chart_quota = Column(Integer, nullable=True) # None = unlimited
    price_monthly = Column(Numeric(10, 2), nullable=False)
    stripe_price_id_monthly = Column(String)
    # ... features JSON ...

class UserSubscription(Base):
    __tablename__ = "user_subscriptions"
    id = Column(String, primary_key=True, default=lambda: str(uuid.uuid4()))
    user_id = Column(String, ForeignKey("users.id"), unique=True)
    plan_id = Column(String, ForeignKey("subscription_plans.id"))
    status = Column(String(20), default="active")
    stripe_customer_id = Column(String)
    current_period_end = Column(DateTime)

    user = relationship("User", back_populates="subscription")
    plan = relationship("SubscriptionPlan")

```

### Step 2: Fix Blocking Code (Async Wrapper)

**Goal:** Prevent synchronous engine calls from blocking.

1. **Create `src/services/engine_bridge.py`:**
Use `run_in_threadpool` to safely execute the synchronous engine code.
```python
from fastapi.concurrency import run_in_threadpool
from src.engine.chart_calculator import calculate_chart_data

async def calculate_chart_async(chart_request):
    """
    Non-blocking wrapper for the CPU-bound chart calculation.
    """
    return await run_in_threadpool(
        calculate_chart_data,
        chart_request.date,
        chart_request.time,
        chart_request.city,
        chart_request.state,
        # ... pass all other arguments explicitly
    )

```
