API Reference

Endpoints

Base URL: https://traditional-astrology.com  ·  Full docs →  ·  OpenAPI spec →

  • POST
    /api/v1/charts/generate
    Full traditional natal chart — dignities, almuten, sect, firdaria, profections, ZR longevity, synthesis with citations. Core B2B endpoint.
  • POST
    /api/v1/synastry
    Traditional synastry analysis between two natal charts. Returns compatibility score, aspects, receptions, and judgment.
  • POST
    /api/v1/charts/bulk/pdf
    Submit up to 50 natal chart requests, receive a ZIP of PDF reports. Returns application/zip.
  • POST
    /api/v1/world
    Global mundane astrology dashboard — current ingresses, eclipses, planetary stations, world forecast.
  • POST
    /api/v1/forensic/audit
    Birth-time rectification via primary directions. Scores candidate times across a range.
  • POST
    /api/v1/charts/calculate
    Full chart calculation with 5-day planetary forecast. Used by the demo.
  • GET
    /api/v1/developer/usage
    Today's API call count and quota remaining.
  • POST
    /api/v1/developer/keys
    Create a new API key. Raw key shown once — store immediately.
